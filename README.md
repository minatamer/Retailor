# Retailor
Retailor is a planned guest ecommerce demo that turns product photos into an AI-drafted catalogue, a fashion storefront and a connected owner dashboard. Visitors will be able to explore both perspectives without signing in, with simulated purchases updating the same demo stock and sales records.

- [Concise visual product overview](docs/RETAILOR_OVERVIEW.html)

The new blueprint is the documentation baseline for the first demo. Application implementation and ticket creation have not started. The intended journey is product photos → AI-drafted catalogue → storefront ↔ owner dashboard, with simulated purchases and synthetic store activity.
