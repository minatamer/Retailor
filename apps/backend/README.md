# Retailor backend

Express factory and bounded provider runtime. Config/runtime/factory imports are inert: no environment loading, listener or external request. `src/server.ts` explicitly loads only app-local `.env.local`, parses config and starts the owned listener. No order/catalogue CRUD database or upload directory exists; commerce mutations happen in the browser session graph.

From repository root run `pnpm dev:backend` in its own terminal, then `pnpm dev:frontend` in another. Backend uses dedicated **4311** and refuses occupied listeners. No key/env file is required for fake development. Ignored `.env.local` is optional; `.env.example` has blank secrets/safe defaults. Dev forces development/fake/paid-off inherited flags without changing the parent. After `pnpm build`, `pnpm start:backend` runs compiled ESM and preserves explicit normal config. Ctrl+C shuts down only the owned server/launcher; never kill a sibling by executable name or port alone.

GET `/v1/health` is content-free liveness; `/v1/ready` reports selected runtime readiness; `/v1/config` exposes safe capabilities. Health/config dispatch no paid request. Fake development supplies declared catalogue/Tailor/logo/FX fixtures. Production rejects fake mode and non-HTTPS frontend origin. Live mode with missing prerequisites remains paid-unavailable (`/ready=503`) and never falls back to fixtures. FX is a separate fixed public reference adapter with bounded reads/cache/deadline. Missing paid keys do not prevent liveness or frontend static operation.

Catalogue, role-bounded Tailor and optional logos use injected ports, exact schemas, origin/challenge/action grants, process-local replay/counter/spend reservations, provider deadlines and shared two-slot AI admission. Native photo preparation has two shared workers and two pending jobs. HTTP admission is four active body handlers and 64 arrivals/minute, distinct from hosted concurrency. [Image concurrency](../../docs/engineering/IMAGE-CONCURRENCY.md) records the Retrosum research and actual native timings. Reservations are not a durable monthly cap; restarts/overlap need operator/provider budget controls.

Docker pins Node/pnpm, installs Linux Sharp from the frozen lockfile, compiles public packages/backend and copies pnpm 11's portable production-only deployment. UID 1000 runs `node dist/server.js` directly, binding 0.0.0.0 in production to supplied `PORT` (default 4311). No env secret, app/test source or runtime package manager is copied. SIGTERM closes only the owned server and forces its remaining connections after five seconds. Startup/liveness uses `/v1/health`, never paid readiness. See [release/IAM/secret/rollback instructions](../../docs/operations/RELEASE.md) and [Linux checks](../../docs/validation/RTL-021.md).

Focused injected HTTP checks: `pnpm exec vitest run apps/backend/src/http/app.test.ts`. Root checks are unpaid and network-isolated. Actual account/AI/billing, Linux paid load and hosted IAM/identity require separate accepted evidence; fixtures cannot supply it.
