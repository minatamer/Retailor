# Dashboard evidence presentation

16 October 2026, RTL-133 owner revision. The shared evidence dialog answers what the figure means, which records contribute and what each record contains before showing implementation precision. It uses a persistent compact close/header, navy/white summary surfaces, small lime accents, readable UTC dates, financial definition lists and garment/linked-record rows. Current operational/inventory balances show their as-of time, separately from selected-period event facts. Record amounts identify their basis, such as original order total or before-discount item amount; they are not presented as additive metric contributions.

All13 record kinds retain their existing historical/current data and links, with order garments and financial breakdowns, return/visit timelines, stock details and review quotations. Never replace a historical snapshot with current catalogue identity. Exact calculations, date inclusions/exclusions, origins, references, timestamps and revision remain inspectable in expandable details. The current metric panel stays mounted but hidden during record inspection, preserving disclosure state and its saved body scroll on Back. New targets reset precision/scroll and focus the shared heading. Native modal/Escape, opener restoration, bounded pagination and existing controller authority remain. Owner operation forms and other dialog workflows retain their own designs and behavior.
