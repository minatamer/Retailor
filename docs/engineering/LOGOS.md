That one deliberate action prepares the exact context and requests a batch; spelling review and actual header preview precede selection. No automatic batch is added. AI operator attention cannot disable local logo controls. Optional failures keep the wordmark/previous choices available.

Browser fake/live mode is session/transport metadata, not a logo-provider choice: both use `brand/local.ts`. Development retains its bounded local route gate. Production/live keeps the original Turnstile proof, HMAC action grant, server-issued safety cookie, boot/expiry/replay checks and exact name-digest/theme/type/revision/count/policy binding. It needs existing Turnstile secret/site and signing credentials, independently of the AI paid master/OpenAI key. Missing protection prerequisites close the native capability. Admission explicitly refuses catalogue/chat actions when their paid runtime is absent.

Composition shares one admission/cookie authority across enabled recognition, native logos and sandbox checkout. A configured signing secret is used when available; a process-generated secret supports existing checkout identity when none is configured, without bypassing production logo prerequisites. Initial/issued/per-identity ingress classification is retained. Logos use the existing shared active slot (one/workspace, two/process), two batches, identity/global rates, bounded operation records and two-hour workspace lifetime. Native generation has known zero model usage; catalogue/chat token and unknown-dispatch accounting is unchanged.

Automatic approval review rejected the initial proposal to remove logo anti-bot verification. The implemented alternative retains those original controls while removing the AI image provider.

## Bundled typography and bounded raster output

Inter600, DM Serif Display400 and Manrope700 match the chosen storefront face/palette. Three authored clothing-brand compositions pair the literal name and initial with an atelier stamp, open circular monogram or woven label. Long names fit balanced lines using real raster bounds. XML/Pango text is escaped. Native text/composite operations each have a ten-second timeout, plus existing operation deadline/cancellation checks.

Renamed static TTFs derive from existing licensed frontend WOFF2 files. OFL notices, source/output SHA256 and glyph ranges accompany them. Offline preparation uses fonttools4.60.1/Brotli1.2.0; neither is a runtime dependency. Build copies seven fixed assets into `dist/brand/fonts` and prunes only fixed compiled outputs for retired image adapters/renamed modules, preventing stale generators in incremental portable packages. Fingerprints include exact font/license/provenance/copy-script bytes; TTFs are Git binary files.

The bundled Latin subset is not full Unicode coverage. Unsupported letters are refused before font substitution; other lettering can keep the storefront wordmark. Names are not rewritten or returned as tofu. Covered names need no host-font lookup/download. [RTL-100 evidence](../validation/RTL-100.md) includes reproducible assets and nine identical PNG hashes under normal/empty-host Fontconfig on Windows. Actual Linux/hosted rendering remains separately unverified.

The strict request stays64KiB maximum; backend total180seconds, generator subdeadline150seconds and bridge/browser195seconds. Exactly three distinct transparent PNGs are required, each at most1024px/one megapixel/1MiB; candidates total3MiB and response envelope4,404,020bytes. Server decoding checks real signature/pixels/alpha, crops only empty padding, strips metadata and derives hashes/dimensions. Independent browser verification uses terminable ten-second workers. Partial sets cause no repair request or hidden retry.
