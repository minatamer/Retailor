11 November 2026. [Ticket](../tickets/RTL-186-responsive-dashboard-tabs.md), [file allocation](../commit-plans/RTL-186.md). Previous WIP is preserved.

## Root cause and implementation

The controls change local presentation state; they do not download new dashboard data. Each new period rebuilt the full model, and both overview and owner conversation consumers could request the same projection. Within that calculation, facts and breakdowns repeatedly ran full schema, relationship and ledger validation on the same immutable graph. Existing `useMemo` only remembered the last period and did not share results between consumers.

- `parseGraph` now recognizes only its own fully validated, schema-cloned and deeply frozen outputs through a private weak registry. Caller inputs are never registered. Mutable, shallow-frozen, deeply frozen, restored or same-ID/revision lookalikes still run the entire validator. Graph schema children contain no opaque/custom/unknown values or schema-level shallow readonly objects. Date/scope checks and session expiry/role/restore/reset ownership are unchanged.
- `dashboardModel` validates the graph and runtime period, then shares a deeply frozen projection for each of the three allowed periods per canonical graph. Weak graph ownership and the runtime enum bound retention; a changed graph gets a different key even when IDs/revisions match. Financial formulas, full history, exact evidence, currency and stock semantics are unchanged. Existing overview/conversation consumers use this shared function without additional state owners.
- Removed only the trend's visible heading, subtitle and heading arrow. Its section is named “Sales and operating profit” for accessibility, and its exact table retains that identity. Other panels retain their headings. Series controls, signed zero reference, curves, context markers and directional number/curve motion remain.
- Synchronous persistence was measured but left unchanged: five serializations cost 75.613ms before and 87.529ms after. Moving it into a hidden queue was not justified. No speculative prefetch, artificial delay, loader or animation suppression was added.
