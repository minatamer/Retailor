## Implementation

The dashboard now builds a shape-preserving cubic Bézier stroke and matching filled area through the exact chart coordinates. Weighted harmonic tangents and a shared tangent limiter keep joins smooth without inventing peaks, overshooting observations or dipping below a positive zero run. Identical padded endpoints collapse safely. Empty, single, two-point, flat, signed and nonuniform-coordinate cases are covered; invalid coordinates fail closed. The chart still supplies at most 32 points.

Initial render and every motion frame use the same curve geometry. The existing 550ms entry and 400ms update timings remain. Cancellation fences late callbacks; the final frame uses the exact target coordinates, avoiding tiny interpolation cancellation errors at duplicate endpoints. Removed idle vertex dots; hover, keyboard focus and explicitly pinned observations retain one contextual marker, exact tooltip and evidence access. Palette, fill, straight zero reference, model, period scope, commerce calculations and existing counters remain.
